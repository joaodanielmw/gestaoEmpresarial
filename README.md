# Gestão Empresarial
Um projeto de estudos com PHP/Laravel

## Como iniciar
### Pré-requisitos
- php 8.2.12
- composer
- npm

### Inicializando
No diretório do projeto, execute os seguintes comandos em suas respectivas ordens no terminal:
```
> composer install
> cp .env.example .env
> php artisan key:generate
> php artisan storage:link
> php artisan serve
```
Em outro terminal, inicialize o servidor do vite:
```
> npm install
> npm run dev
```

conecte-se à `127.0.0.1:8000` (localhost)
