# Gestão Empresarial
Um projeto de estudos com PHP/Laravel

## Como iniciar
### Pré-requisitos
- php 8.2.12
- composer
- npm

### Inicializando
No diretório do projeto, execute os seguintes comandos no cli:
```
> composer install
> php artisan serve
```
Em outro terminal, inicialize o servidor do vite:
```
> npm install
> npm run dev
```

conecte-se à `127.0.0.1:8000` (localhost)

## Atenção
Apenas os formulários foram criados, as seções de usuário (login e registro) ainda não foram implementadas, para acessar as funcionalidades de administrador é necessário a seguinte URL:

```
127.0.0.1:8000/admin/dashboard
```
